# Paragraph tabs and TOC leaders implementation plan

> Execute inline with the executing-plans skill, using failing regressions before
> implementation and a focused independent review before publishing.

**Goal:** Preserve and lay out paragraph tab stops and generate a TOC with
right-aligned page numbers and real dot leaders.

**Architecture:** Extend ParagraphFormat and its existing style cascade, WFG and
DOCX paths. The shaper positions tab fields using real shaped widths; layout supplies
the line's offset within its paragraph writing area. Leaders are shaped glyphs attached
to a tab's range, so the existing renderer and PDF path draw them.

**Constraints:** C++20, Qt6 Widgets, Skia m143, HarfBuzz, FreeType and ICU unchanged.
Core and layout stay independent of widgets. Work from main dd2730a in an isolated
branch; PR #39 stays open. No merge, release or stable promotion.

**Scope choices:** left/centre/right stops in points from the paragraph writing area's
left edge; no leader/dots; 36 pt automatic stops. Import resolves style stops by position
and clear entries before storing the resolved list. Unsupported decimal/bar/RTL-specific
semantics and other leader styles warn on import. No tab ruler UI in this slice.
The existing TOC commands are the end-user workflow for the feature.

**Alternatives:** Repeated periods in TOC text cannot align proportional fonts or resize
correctly. A separate TOC renderer would duplicate layout and export semantics. Real
paragraph stops reuse the document pipeline and permit DOCX interoperability.

## Tasks and checks

- [ ] Model/style/native: add TabStop with alignment/leader enums and sorted positions,
  ParagraphFormat::tabs, ParagraphProperties::tabs, TabsField. Validate finite strictly
  increasing positions in [0,2880], supported enums and at most 64 stops. Inherit and
  mask them through existing style helpers. WFG14 only when stops/style stop overrides
  are used; old files retain current version and 36 pt defaults. Test style/undo,
  exact persistence, old-file reading, invalid stops and old-version rejection.
- [ ] Shaping/layout: position left/centre/right fields from shaped text widths, include
  line origin when measuring stops, retain tab caret edges and glyph-free tab ranges;
  leaders use ordinary shaped dot glyphs with the tab's cluster. Test aligned edges,
  consecutive tabs, first-line indents, wrapping, mixed formatting, caret/hit testing,
  cache invalidation and narrow writing areas. Keep aligned tab and following field
  together when wrapping. No changes to pagination architecture.
- [ ] DOCX/TOC: parse/write w:tabs at defaults/style/direct levels, merge/clear by
  position, warn on unsupported semantics. Generated and updated TOC entries get a
  right dot-leader stop at their section column's right edge. Test XML independently,
  style inheritance/clears, save/reopen and TOC updates/undo with long headings.
- [ ] Verify Windows and Ubuntu builds and all six suites; check native TOC workflow
  and representative Word round trips where available. Update schema/status/handoff,
  record actual limits and results, review, commit/push and open PR into main.

## Review focus

Long titles must wrap without detaching page numbers from their tab. Tabs must retain
exact caret boundaries even with decorative dots. Missing fonts use the existing
fallback. Invalid native data must fail transactionally. Unsupported DOCX tab semantics
must warn rather than silently claim fidelity.
