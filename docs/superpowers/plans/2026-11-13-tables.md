# Editable tables implementation plan

> For agentic workers: use subagent-driven-development for the independent format
> adapter task; root owns tightly coupled model/layout/desktop work.

Goal: Insert real rectangular tables, edit styled multi-paragraph cells, navigate
with Tab/Shift+Tab, add/delete rows and columns, delete tables, undo, save/reopen,
recover, render/PDF and DOCX export. Preserve all existing picture/bookmark paths.
Spec: ENGINEERING_DIRECTIVE.md, ENGINEERING_ROADMAP.md phases1B/5A and user's Word
Insert screenshot. User authorizes autonomous increments and per-feature pushes.

Architecture decision: keep one authoritative paragraph store and introduce typed
TableCell membership on paragraphs plus Table geometry metadata, not fake tab text
or an independent widget editor. Cell paragraphs remain contiguous in row-major
order; every rectangular cell contains at least one paragraph. This is an explicit
limited block-structure migration, not completion of the full section/block tree.
IDs share the checked allocator. Stable bookmarks survive structural edits; deleted
cell bookmarks collapse to a surviving document position. Normal replacement may
join paragraphs only within one cell or within body text, never across boundaries.

Contract:
- TableCell { uint64_t tableId; size_t row,column; == };
  Paragraph::cell optional<TableCell>.
- Table { uint64_t id; size_t rows,columns; == }; Document::tables vector<Table>.
  Grid uses equal page-body-width columns, 4pt cell padding, warm brown borders.
  Limits: 1..1000 rows,1..10 columns; no nested/merged cells in this slice.
- validateTables(Document) enforces contiguous complete row-major cells, no orphan
  membership, exact ID scope, at least one body paragraph after each table.
- Editor::insertTable(rows,columns), tableRow(bool insert,bool before=false),
  tableColumn(bool insert,bool before=false), removeTable(), nextCell(bool backward),
  selectedCell() optional<TableCell>. Structural commands grouped atomically.
- ChangeSet::tablesChanged; tables and allocator high-water included in transactions.
- WFG5 ZIP for tables (with or without pictures), readsWFG1..5; table metadata and
  paragraph cell attributes retained. WFG4 remains image-only prior compatibility.
- DOCX exports real w:tbl/w:tr/w:tc including multiple paragraphs/images per cell;
  DOCX table import remains an explicit unsupported-content warning in this slice.

Tasks and evidence:
- [x] Core: failing command/undo/paragraph-split/boundary/structural/bookmark tests;
  implement typed membership, validation and atomic commands in tables.cpp.
- [x] Layout/render: real cell widths, max row heights, whole-row pagination,
  hit testing/caret, borders/PDF. Reject a row taller than a page before UI commits.
  Tests: side-by-side caret positions, wrapped cells, page boundary and tall rollback.
- [x] Independent formats: WFG5 validation/roundtrip and real DOCX table export,
  text/image mixtures and malformed membership tests; legacy readers unchanged.
- [ ] Desktop: Insert Table dimension dialog, context-enabled row/column controls,
  delete and Tab navigation; tests use real Qt buttons and file workflows.
- [ ] Review, both native ARM64 platform suites, independent DOCX parser,
  updated capability/handoff/evidence, focused commit and push.

Review risks: cells must never silently merge on Backspace/Delete; Enter creates
another paragraph in the same cell; row deletion must repair bookmarks/resources;
geometry changes must invalidate scenes; tall rows must preserve active document.
Remaining: merge/split, custom widths/styles/borders, repeated headers, row splitting,
selection of cell ranges, nested tables, DOCX table import. Do not call full Insert
or full phase5A complete. No new dependencies or co-author trailers/history rewrites.

```cpp
    void tableDialogEditingStructureAndFileWorkflow() {
        wf::MainWindow window; window.show();
        auto *view=window.pageView(); view->setDocument({});
        // The ribbon was removed on 2026-11-13; Insert Table is a registered command.
        auto *action=window.findChild<QAction *>("tableAction"); QVERIFY(action);
        bool inserted=false;
        QTimer::singleShot(0,&window,[&] {
            if(auto *dialog=qobject_cast<QDialog *>(QApplication::activeModalWidget())) {
                auto *rows=dialog->findChild<QSpinBox *>("tableRows");
                auto *columns=dialog->findChild<QSpinBox *>("tableColumns");
                if(rows && columns) {
                    rows->setValue(2); columns->setValue(2);
                    dialog->findChild<QDialogButtonBox *>()->button(QDialogButtonBox::Ok)->click();
                    inserted=true;
                } else dialog->reject();
            }
        });
        action->trigger(); QVERIFY(inserted);
        QCOMPARE(view->document().tables.size(),std::size_t(1));
        view->insertText("Left"); QTest::keyClick(view,Qt::Key_Tab); view->insertText("Right");
        QCOMPARE(view->selection().focus.paragraph,std::size_t(2));
        QTest::keyClick(view,Qt::Key_Backtab);
        QCOMPARE(view->selection().focus.paragraph,std::size_t(1));
        auto *row=window.findChild<QAction *>("insertRowAfter"); QVERIFY(row); QVERIFY(row->isEnabled());
        row->trigger(); QCOMPARE(view->document().tables[0].rows,std::size_t(3));
        view->undo(); QCOMPARE(view->document().tables[0].rows,std::size_t(2));
        QTemporaryDir directory;
        window.saveFile(directory.path()+"/table.wfg");
        window.saveFile(directory.path()+"/table.docx");
        view->exportPdf(directory.path()+"/table.pdf");
        QVERIFY(QFileInfo(directory.path()+"/table.pdf").size()>100);
        wf::MainWindow restored; restored.openFile(directory.path()+"/table.wfg");
        QCOMPARE(restored.pageView()->document().tables.size(),std::size_t(1));
        QCOMPARE(restored.pageView()->document().paragraphs[1].text(),std::u16string(u"Left"));
        QCOMPARE(restored.pageView()->document().paragraphs[2].text(),std::u16string(u"Right"));
    }
```
