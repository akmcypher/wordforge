# Wordforge 0.6.10

Widow/orphan control and superscript/subscript. This release also lines up the
Windows downloads with the Snap packages: Snap stable already carried these
features under the 0.6.9 label.

## Changes since 0.6.9

- **Widow and orphan control:** a Format panel checkbox stops a paragraph's
  first or last line from sitting alone at the top or bottom of a page. It
  follows paragraph styles and direct formatting, and works with columns,
  continuous sections and footnotes. Explicit breaks and keep-with-next groups
  take priority, and the rule relaxes when it can't be met. New native documents
  default to off. DOCX files without a setting default to on, as in Word.
- **Superscript and subscript:** available from the Format menu and panel, the
  command palette, Ctrl+Shift+= (superscript) and Ctrl+= (subscript). The modes
  exclude each other, and choosing the active mode returns to normal text. The
  setting follows styles, round-trips through DOCX `vertAlign` and survives HTML
  copy and paste. Text is drawn at 65% size with a fixed offset, which
  approximates Word's metrics but doesn't match them exactly.
- **Snap promotion:** a manual, main-only workflow checks a Store revision's
  archive hashes, embedded source commit and executable hash before promoting
  it to stable.

## Downloads

Windows x64 and ARM64 installers and portable ZIPs are published with checksums.
The installers are per-user and unsigned; trusted code signing isn't configured,
so Windows security warnings may appear.

Snap packages for amd64 and ARM64 use version `0.6.10-preview`. Stable promotion
happens separately, after package builds and strict-confinement checks.

Native documents use WFG16 for widow/orphan settings and WFG17 for superscript or
subscript. The reader supports WFG1–17. Wordforge 0.6.9 and earlier on Windows
can't open these files; keep copies when exchanging documents.

## Known limitations

This is still a developer preview with partial DOCX support. Unknown body content
may be dropped with a warning; this isn't full DOCX preservation. Notes and
comments are plain text. Columns aren't balanced, and section headers apply to the
whole document. Incremental and background pagination and full screen-reader
support are future work. Word 97–2003 .doc, RTF and .odt aren't supported.

Automated structural Word checks don't certify visual parity. No new Word
automation result is recorded for superscript/subscript.
