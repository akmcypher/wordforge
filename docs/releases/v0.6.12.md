# Wordforge 0.6.12

Faster typing in long documents, again. This release has no new features or format
changes.

## Changes since 0.6.11

Typing in a 1000-page document (32,000 paragraphs, Windows ARM64, including the screen
repaint) now takes a median of about 3.1–3.7 ms per keystroke, against about 5.6 ms in
0.6.11 and 181–185 ms in 0.6.10.

- **Pagination keys:** after an edit, Wordforge recomputes the layout inputs only of the
  paragraphs that changed, instead of all of them.
- **Layout checkpoints:** the saved layout state for each paragraph is updated in place
  instead of being copied on every edit.

The incremental layout is still checked against a fresh full layout after every edit in
the tests, including 150 random edits.

## Downloads

Windows x64 and ARM64 installers and portable ZIPs are published with checksums.
The installers are per-user and unsigned; trusted code signing isn't configured,
so Windows security warnings may appear.

Snap packages for amd64 and ARM64 use version `0.6.12-preview`. Stable promotion
happens separately, after package builds and strict-confinement checks.

The native format is unchanged: WFG17, and the reader supports WFG1–17.

## Known limitations

This is still a developer preview with partial DOCX support. Unknown body content
may be dropped with a warning; this isn't full DOCX preservation. Notes and
comments are plain text. Columns aren't balanced, and section headers apply to the
whole document. Layout still runs on the editing thread (background and
visible-page-first layout are future work), and full screen-reader support is future
work. Word 97–2003 .doc, RTF and .odt aren't supported.

The performance figures are single runs on synthetic text on one machine, not
certified latency targets.
