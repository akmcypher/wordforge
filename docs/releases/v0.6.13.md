# Wordforge 0.6.13

Word documents open more faithfully and far less often behind the import warning. In a
test set of 114 documents saved by Microsoft Word, 88 now open without the
import-limitations dialog; in 0.6.12, none did.

## Changes since 0.6.12

- **Word table styles:**
  - A table's style is applied on import: whole-table, banded rows and columns,
    first/last row and column, corner shading, text and paragraph formatting, and the
    style's borders.
  - They are saved back as direct formatting. The style name isn't kept.
- **Word's style defaults:**
  - Options Word writes into every document are kept and saved back into the same styles,
    including kerning, ligatures, heading outline levels and a document grid without a type.
  - Those that look the same in Wordforge no longer cause a warning. Others warn as "kept
    but not shown".
- **Paragraph and letter spacing:**
  - Word's "Don't add space between paragraphs of the same style" and character spacing
    (expanded or condensed text) are shown, edited in the Format panel and saved both ways.
  - Letter-spaced text isn't joined into ligatures.
- **Multilevel lists:**
  - Lists have nine levels. Each level has its own number style (1, a, A, i, I, bullets or
    none), label (such as `1)` or `1.2.`) and start.
  - Separate Word lists number separately, and a level restarts under each new parent.
  - Word's Symbol and Wingdings bullets show as their Unicode look.
  - Increase and Decrease indent on a list item move it between levels, as in Word.

Typing in a 1000-page document takes about the same time as in 0.6.12: a median of about
3.5 ms per keystroke.

## Downloads

Windows x64 and ARM64 installers and portable ZIPs are published with checksums.
The installers are per-user and unsigned; trusted code signing isn't configured,
so Windows security warnings may appear.

Snap packages for amd64 and ARM64 use version `0.6.13-preview`. Stable promotion
happens separately, after package builds and strict-confinement checks.

The native format is now **WFG18**. The reader supports WFG1–18. WFG18 is written only
for documents that use the new spacing or list options; others keep their earlier
version and still open in 0.6.12.

## Known limitations

This is still a developer preview with partial DOCX support. Unknown body content may be
dropped with a warning; this isn't full DOCX preservation. Notes and comments are plain
text.
- **Lists:** Word's heading numbering defined in styles is read only where a paragraph's
  style carries the numbering. Wordforge's own numbered lists restart after a paragraph
  outside the list.
- **Untested:** saved files haven't been checked in Word itself in this release, because
  Word automation was unavailable.
- **Pages:** columns aren't balanced, and section headers apply to the whole document.
- **Layout and accessibility:** layout still runs on the editing thread. Full screen-reader
  support is future work.
- **Other formats:** Word 97–2003 .doc, RTF and .odt aren't supported.

The corpus counts and performance figures come from one machine, not certified targets.
