# Wordforge 0.6.14

All 114 documents in a test set saved by Microsoft Word now open without the
import-limitations dialog, up from 88 in 0.6.13. The last three gaps were bookmarks,
even-page headers and borders on single table cells.

## Changes since 0.6.13

- **Bookmarks:**
  - Word bookmarks are kept as places or named ranges. Go to selects a bookmark's range.
  - Saving a document with bookmarks as a Word file now works; it used to fail.
  - Names Word wouldn't accept, such as names with spaces, are renamed in the saved file.
    Links to them follow.
  - The Bookmarks dialog hides Word's hidden bookmarks (names starting with `_`, such as
    `_Toc…`) unless "Hidden bookmarks" is ticked.
- **Even-page headers and footers:**
  - Word's "Different odd and even pages" is shown: even pages use their own header and
    footer.
  - Set them in Header and footer. They're kept when saving as a Word file.
- **Table cell borders:**
  - Each side of a cell can have its own line, as in Word, from the cell, the table or its
    table style, such as a line under a header row.
  - On a side two cells share, the wider line shows.
  - Choosing the table's border in Table border applies it to every cell.

## Downloads

Windows x64 and ARM64 installers and portable ZIPs are published with checksums.
The installers are per-user and unsigned; trusted code signing isn't configured,
so Windows security warnings may appear.

Snap packages for amd64 and ARM64 use version `0.6.14-preview`. Stable promotion
happens separately, after package builds and strict-confinement checks.

The native format is now **WFG19**. The reader supports WFG1–19. WFG19 is written only
for documents with bookmark ranges, even-page headers or footers, or cell borders; others
keep their earlier version and still open in 0.6.13.

## Known limitations

This is still a developer preview with partial DOCX support. Unknown body content may be
dropped with a warning; this isn't full DOCX preservation. Notes and comments are plain
text.
- **Borders:** dashed, double and other border styles are drawn as single lines, and
  diagonal cell borders aren't drawn. Both cases warn on import.
- **Headers:** first-page header text still isn't shown, and section headers apply to the
  whole document.
- **Untested:** saved files haven't been checked in Word itself in this release, because
  Word automation was unavailable. The 1000-page typing benchmark couldn't be measured
  reliably for this release, because the test machine was busy; the benchmark document
  doesn't use these features.
- **Pages:** columns aren't balanced.
- **Layout and accessibility:** layout still runs on the editing thread. Full screen-reader
  support is future work.
- **Other formats:** Word 97–2003 .doc, RTF and .odt aren't supported.

The corpus counts come from one machine, not certified targets.
