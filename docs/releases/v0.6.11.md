# Wordforge 0.6.11

Faster editing in long documents. This release has no new features or format changes:
it removes per-keystroke work that grew with the size of the document.

## Changes since 0.6.10

Typing in a 1000-page document (32,000 paragraphs, Windows ARM64, including the screen
repaint) now takes a median of about 5.6 ms per keystroke, against 181–185 ms in 0.6.10.

- **Incremental pagination:** after an edit, Wordforge lays out again only from just
  before the change until the pages match the previous layout, then reuses the rest.
  Endnotes are still laid out again each time; headers and footers are reused while their
  text, page count and page size stay the same.
- **Page redraw:** only pages whose layout changed are re-recorded for drawing.
- **Shared document storage:** an edit and its undo history no longer copy the whole
  document. Undo and redo are near-instant on long documents, and peak memory in a
  34,000-paragraph editing benchmark dropped from 126 MiB to 36 MiB.
- **Word count:** the status bar and Word Count dialog recount only the paragraphs that
  changed.
- **Spell-check underlines:** drawing them no longer walks every page of the document.

Every one of these is checked against the full, non-incremental result. The pagination
tests compare each edit, including 150 random edits, line by line with a fresh layout. The
render test compares pixels with a fresh renderer, and the word count is checked against
a full recount.

## Downloads

Windows x64 and ARM64 installers and portable ZIPs are published with checksums.
The installers are per-user and unsigned; trusted code signing isn't configured,
so Windows security warnings may appear.

Snap packages for amd64 and ARM64 use version `0.6.11-preview`. Stable promotion
happens separately, after package builds and strict-confinement checks.

The native format is unchanged: WFG17, and the reader supports WFG1–17.

## Known limitations

This is still a developer preview with partial DOCX support. Unknown body content
may be dropped with a warning; this isn't full DOCX preservation. Notes and
comments are plain text. Columns aren't balanced, and section headers apply to the
whole document. Layout still runs on the editing thread (background and
visible-page-first layout are future work), and full screen-reader support is future
work. Word 97–2003 .doc, RTF and .odt aren't supported.

The performance figures are single runs on synthetic text on one machine, not
certified latency targets.
