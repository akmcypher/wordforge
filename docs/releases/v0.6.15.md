# Wordforge 0.6.15

Three of the known limitations of 0.6.14 are fixed: Word documents now show their
first-page headers and footers, dashed, dotted and double table borders, and diagonal
lines across table cells.

## Changes since 0.6.14

- **First-page headers and footers:**
  - Word's "Different first page" header and footer text is shown on the first page. It
    used to be dropped, leaving the first page blank.
  - Set it in Header and footer, under "Different header and footer on the first page".
    It's kept when saving as a Word file.
- **Table border styles:**
  - Dashed, dotted and double borders are drawn as such. They used to be single lines.
  - Choose a style in Table borders. Styles are kept when saving as a Word file.
- **Diagonal cell borders:**
  - Word's diagonal lines across table cells are drawn and kept when saving as a Word
    file. They can't be added in Wordforge yet.

## Downloads

Windows x64 and ARM64 installers and portable ZIPs are published with checksums.
The installers are per-user and unsigned; trusted code signing isn't configured,
so Windows security warnings may appear.

Snap packages for amd64 and ARM64 use version `0.6.15-preview`. Stable promotion
happens separately, after package builds and strict-confinement checks.

The native format is now **WFG20**. The reader supports WFG1–20. WFG20 is written only
for documents with first-page header or footer text, dashed, dotted or double borders, or
diagonal cell borders; others keep their earlier version and still open in 0.6.14.

## Known limitations

This is still a developer preview with partial DOCX support. Unknown body content may be
dropped with a warning; this isn't full DOCX preservation. Notes and comments are plain
text.
- **Borders:** wavy, triple, 3-D and other border styles are drawn as single lines, with
  a warning. A cell's own borders can't be set in the editor.
- **Headers:** the first page is the document's first page only, and section headers
  apply to the whole document.
- **Untested:** saved files haven't been checked in Word itself in this release, because
  Word automation was unavailable, and the drawn border styles haven't been compared with
  Word's.
- **Pages:** columns aren't balanced.
- **Layout and accessibility:** layout still runs on the editing thread. Full screen-reader
  support is future work.
- **Other formats:** Word 97–2003 .doc, RTF and .odt aren't supported.

The corpus counts come from one machine, not certified targets.
