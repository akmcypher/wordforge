Adds a Windows installer, publishes the Snap on the stable channel, and introduces
paragraph styles you can customise.

## Downloads

**Windows 10 (1903+) and Windows 11**

* `Wordforge-0.6.2-windows-x64-setup.exe` — installer for most PCs
* `Wordforge-0.6.2-windows-arm64-setup.exe` — installer for Arm PCs (Snapdragon and similar)

The installer needs no administrator rights. It adds a Start menu entry, an
uninstaller (Settings → Apps), opens `.wfg` files in Wordforge and adds Wordforge to
"Open with" for `.docx` and `.txt` without changing their default program.

Portable versions, nothing to install: `Wordforge-0.6.2-windows-x64.zip` and
`Wordforge-0.6.2-windows-arm64.zip`. Unzip the whole folder, then run `Wordforge.exe`.

The builds are not code-signed yet, so SmartScreen may ask you to confirm the first
launch (More info → Run anyway). Checksums are in `SHA256SUMS.txt`.

**Ubuntu (amd64, arm64)**: `sudo snap install wordforge` (https://snapcraft.io/wordforge)

## Changes since 0.6.1

* Windows installer (`-setup.exe`), tested in CI by a silent install, self-test and
  uninstall on x64 and ARM64.
* Paragraph styles with inheritance: Normal, Title, Heading 1 and Heading 2 are real
  styles; changing a style restyles the text that uses it and keeps direct
  formatting. Documents with customised styles are saved as WFG6, which 0.6.1 cannot
  open; documents using only the built-in styles stay readable by 0.6.x.
* Snap: published on the stable channel and listed in Snap Store search. Printing
  uses the CUPS socket directly, so it works under strict confinement without
  network access. Every Snap is installed and self-tested under strict confinement
  in CI before upload.

## Known limitations

* No headers and footers, footnotes, comments or tracked changes yet.
* Tables cannot merge cells or set column widths; DOCX tables and pictures are
  not imported; floating or wrapped pictures are not supported.
* Custom style definitions are not exported to DOCX yet (text keeps its formatting).
* Word features Wordforge does not understand are not preserved on DOCX export.
* Visual caret movement through mixed-direction text and screen-reader support
  are incomplete.
* Windows packages are not code-signed and have not been tested on a fresh Windows 10
  installation.
* The Snap's strict confinement is tested headless in CI, not yet interactively on a
  real Ubuntu desktop.

Please report problems at https://github.com/akmcypher/wordforge/issues.
