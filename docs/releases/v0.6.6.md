Adds tracked changes: review edits and accept or reject them, also in Word documents.

## Downloads

**Windows 10 (1903+) and Windows 11**

* `Wordforge-0.6.6-windows-x64-setup.exe` — installer for most PCs
* `Wordforge-0.6.6-windows-arm64-setup.exe` — installer for Arm PCs (Snapdragon and similar)

The installer needs no administrator rights. It adds a Start menu entry and an
uninstaller (Settings → Apps), opens `.wfg` files in Wordforge and adds Wordforge to
"Open with" for `.docx` and `.txt`.

Portable versions, nothing to install: `Wordforge-0.6.6-windows-x64.zip` and
`Wordforge-0.6.6-windows-arm64.zip`. Unzip the whole folder, then run `Wordforge.exe`.

The builds are not code-signed yet, so SmartScreen may ask you to confirm the first
launch (More info → Run anyway). Checksums are in `SHA256SUMS.txt`.

**Ubuntu (amd64, arm64)**: `sudo snap install wordforge` (https://snapcraft.io/wordforge)

## Changes since 0.6.5

* **Tracked changes.** Review → Track changes (Ctrl+Shift+E) records what you type and
  delete under your name: new text is underlined and deleted text struck through, in red.
  Deleted text stays until accepted; deleting your own new text simply removes it.
  Review → Next change, Accept change and Reject change work on the selection or the
  change at the cursor and move on to the next one; Accept all and Reject all finish a
  review. All of this can be undone.
* **Word documents with tracked changes.** Insertions, deletions and moved text from Word
  open as tracked changes, and Wordforge saves its changes and the Track Changes switch
  back to DOCX. Before this, text Word had marked as inserted was dropped when opening.

Documents with tracked changes, or with Track Changes switched on, are saved as WFG10,
which 0.6.5 cannot open. Other documents keep their earlier format.

## Known limitations

* New paragraphs, formatting changes and table changes are not tracked yet; changes have
  one colour for every reviewer and no margin balloons. Word count, find and plain-text
  export still include deleted text.
* Footnotes and comments are plain text, one paragraph each; no endnotes, comment
  replies or resolved state.
* Word content inside the text that Wordforge does not understand (endnotes, fields,
  formatting revisions) is still left out when saving, with a warning when you open the
  file.
* Headers and footers are plain text in one line; tables have no row heights, shading or
  draggable borders; pictures cannot float or wrap text.
* The new DOCX features have not yet been checked in Microsoft Word or LibreOffice.
* Visual caret movement through mixed-direction text and screen-reader support are
  incomplete.
* Windows packages are not code-signed and have not been tested on a fresh Windows 10
  installation.
* The Snap's strict confinement is tested headless in CI, not yet interactively on a
  real Ubuntu desktop.

Please report problems at https://github.com/akmcypher/wordforge/issues.
