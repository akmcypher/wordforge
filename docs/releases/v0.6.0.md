The first public developer preview of Wordforge, a native word processor written in
C++20 with Qt 6, Skia, HarfBuzz, FreeType and ICU.

## Downloads

**Windows 10 (1903+) and Windows 11** — portable, nothing to install:

* `Wordforge-0.6.0-windows-x64.zip` for most PCs
* `Wordforge-0.6.0-windows-arm64.zip` for Arm PCs (Snapdragon and similar)

Unzip anywhere and run `Wordforge.exe`. The builds are not code-signed yet, so
SmartScreen may ask you to confirm the first launch (More info → Run anyway).
Checksums are in `SHA256SUMS.txt`. `Wordforge.exe --self-test report.txt` checks an
installation.

**Ubuntu (amd64, arm64)**: `sudo snap install wordforge --edge`

## What works

Page layout with styles, lists, indentation and spacing; tables; PNG/JPEG
pictures; bookmarks; find and replace; offline spell check (Hunspell, English
dictionaries included on Windows); copy and paste with formatting; printing and
print preview; PDF export; native `.wfg` files and partial DOCX import/export;
HarfBuzz shaping for Arabic, Hebrew, Devanagari, CJK and emoji; crash recovery;
light and dark themes, a Ctrl+K command palette and F11 focus mode.

## Known limitations

* No headers and footers, footnotes, comments or tracked changes yet.
* Tables cannot merge cells or set column widths; DOCX tables and pictures are
  not imported; floating or wrapped pictures are not supported.
* Word features Wordforge does not understand are not preserved on DOCX export.
* Visual caret movement through mixed-direction text and screen-reader support
  are incomplete.
* Windows packages have been tested on Windows 11 (ARM64 on a developer machine,
  x64 on GitHub's runners) but not yet on a fresh Windows 10 installation. There
  is no installer or code signing yet.
* The Snap's strict confinement has not been tested on a real Ubuntu desktop yet.

Please report problems at https://github.com/akmcypher/wordforge/issues.
